## 🖼️ Customization Guide

### Replace Placeholder Content

1. **Images**: Replace Unsplash URLs with your own images
   - Update `src` attributes in `<img>` tags
   - Recommended sizes:
     - Hero: 1600x900px
     - Projects: 800x600px
     - Team: 400x400px

2. **Text Content**: Update all placeholder text
   - Company details in footer
   - Team member names and bios
   - Project descriptions
   - Contact information

3. **Colors**: Modify CSS variables in `styles.css`
   ```css
   :root {
       --primary-blue: #2563eb;
       --primary-green: #10b981;
       /* ... other colors */
   }
   ```

4. **Logo**: Replace text logo with image
   ```html
   <div class="logo">
       <img src="your-logo.png" alt="ANS-SITI">
   </div>
   ```

### Add Functionality

1. **Contact Form**: Connect to backend service
   - Update form action in `contact.html`
   - Modify `script.js` form handler

2. **Newsletter**: Integrate with email service
   - Update newsletter form handler in `script.js`

3. **Map**: Add Google Maps embed
   - Replace map placeholder in `contact.html`
